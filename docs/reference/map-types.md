# Map Type Reference

Lookup table for all six PBR map types generated by TextureWorks. For full mathematical specifications, see [Algorithm Specifications](../algorithms.md).

## Normal Map

**Purpose in PBR rendering:** Encodes per-pixel surface orientation, allowing a flat polygon to simulate bumps and details without extra geometry. The renderer reads the normal to compute accurate lighting angles.

**Algorithm:** Sobel Gradient to Normal Encoding. Converts to grayscale, computes horizontal and vertical gradients with 3x3 Sobel kernels, constructs a normalized vector, and encodes as RGB.

**Output encoding:** RGB, where R = X component, G = Y component, B = Z component. A flat surface (no detail) encodes as (128, 128, 255) in 8-bit.

**Expected output:** Blue-dominant image. Bright red/green areas indicate angled surfaces. Strong edges in the input produce visible normal variation.

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `strength` | float | 2.0 | [0.1, 20.0] | Depth exaggeration factor. Higher values produce more pronounced surface bumps. At 0.5 the map is subtle; at 10.0 features dominate |

**Comparison tolerance:** 1 (rounding differences only)

---

## Height Map

**Purpose in PBR rendering:** Encodes perceived surface elevation as a grayscale value. Used for parallax mapping, displacement mapping, and as input to AO generation.

**Algorithm:** Luminance Extraction with Contrast Enhancement. Extracts BT.709 luminance, normalizes to full [0, 1] range, applies optional Gaussian blur, then adjusts contrast around the midpoint.

**Output encoding:** Single-channel grayscale. White = high, black = low (unless `invert=True`).

**Expected output:** Grayscale version of the input with enhanced contrast. Bright areas represent surface peaks, dark areas represent valleys.

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `blur_sigma` | float | 1.0 | [0.0, 10.0] | Gaussian smoothing sigma. 0 disables blur. Higher values remove fine detail |
| `contrast` | float | 1.2 | [0.5, 3.0] | Contrast multiplier around 0.5 midpoint. Below 1.0 flattens, above 1.0 increases separation |
| `invert` | bool | False | True/False | Flip height interpretation. Useful for depth-as-height conventions |

**Comparison tolerance:** 2 (blur floating-point variance)

---

## Ambient Occlusion

**Purpose in PBR rendering:** Approximates how much ambient light reaches each surface point. Darkens crevices, corners, and recessed areas. Applied as a multiplier on the final lighting pass.

**Algorithm:** Screen-Space Horizon Mapping from Height Field. For each pixel, casts rays in multiple directions, marches steps along each ray, and measures the maximum elevation angle. Averages occlusion across all directions and applies a power curve.

**Prerequisite:** Requires a height map. If none is provided, one is generated automatically from the input texture.

**Output encoding:** Single-channel grayscale. White = unoccluded (fully lit), black = fully occluded (shadowed).

**Expected output:** Mostly bright image with darkened crevices, panel lines, and recessed details. Open flat areas appear white.

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `num_directions` | int | 16 | [4, 64] | Angular sampling density. More directions produce smoother results at linear cost |
| `max_steps` | int | 20 | [4, 64] | Ray march distance per direction. More steps detect occlusion from farther features |
| `step_scale` | float | 1.0 | [0.5, 4.0] | Pixel distance per step. Larger values extend the reach of occlusion detection |
| `height_scale` | float | 10.0 | [0.1, 50.0] | Height map influence on elevation angle. Higher values make terrain appear taller |
| `power` | float | 1.5 | [0.5, 4.0] | Contrast power curve. Above 1.0 darkens shadows, below 1.0 lightens them |

**Comparison tolerance:** 3 (trigonometric and sampling variance between CuPy and PTX)

---

## Roughness Map

**Purpose in PBR rendering:** Encodes surface micro-roughness, controlling how sharply a surface reflects light. Rough areas scatter reflections (diffuse look), smooth areas produce mirror-like reflections.

**Algorithm:** Local Variance Analysis. Converts to grayscale, computes local variance in a box window and Sobel edge magnitude separately, normalizes both to [0, 1], blends them with a configurable weight, applies Gaussian blur, and adjusts contrast.

**Output encoding:** Single-channel grayscale. White = rough, black = smooth.

**Expected output:** Detailed areas (scratches, texture patterns) appear brighter. Smooth, uniform regions appear darker.

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `radius` | int | 4 | [1, 16] | Analysis window half-size. Window size = 2*radius+1 pixels. Larger windows capture broader texture patterns |
| `alpha` | float | 0.6 | [0.0, 1.0] | Blend weight between variance (1.0) and edge density (0.0). At 0.6, variance dominates |
| `blur` | float | 1.0 | [0.0, 5.0] | Output smoothing sigma. Blends nearby roughness estimates |
| `contrast` | float | 1.5 | [0.5, 3.0] | Output contrast multiplier. Higher values push roughness toward black and white extremes |

**Comparison tolerance:** 3

---

## Metallic Map

**Purpose in PBR rendering:** Classifies pixels as metallic or dielectric (non-metal). Metallic surfaces reflect their base color; dielectric surfaces have white specular highlights. Most PBR shaders use this as a binary or near-binary mask.

**Algorithm:** HSV Saturation and Value Thresholding. Converts to HSV color space, computes a saturation score (metals are desaturated) and a value score (metals are bright), multiplies them for the final metallic probability, applies Gaussian blur, and optionally applies a binary threshold.

**Output encoding:** Single-channel grayscale. White = metallic, black = dielectric.

**Expected output:** Bright areas on desaturated, bright surfaces (bare metal, chrome). Dark areas on colored or dark surfaces (paint, rubber, fabric).

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `sat_threshold` | float | 0.35 | [0.05, 0.5] | Maximum saturation for metal. Lower values restrict metal classification to very desaturated pixels |
| `val_threshold` | float | 0.10 | [0.01, 0.8] | Minimum brightness for metal. Higher values exclude darker areas from metal classification |
| `val_range` | float | 0.3 | [0.1, 1.0] | Soft transition width above val_threshold. Larger values create smoother boundaries |
| `blur` | float | 2.0 | [0.0, 5.0] | Output smoothing sigma. Larger values feather the boundaries |
| `hard_edges` | bool | False | True/False | Apply binary threshold at 0.5 for crisp 0/1 boundaries |

**Comparison tolerance:** 2

---

## Specular Map

**Purpose in PBR rendering:** Encodes per-pixel specular reflectance intensity. Controls how bright the specular highlight is on each pixel. Used in specular/glossiness PBR workflows (as opposed to metallic/roughness).

**Algorithm:** Luminance-Weighted Saturation Inversion. Extracts luminance and saturation, computes base specular as `luminance * (1 - saturation * sat_weight)`, normalizes to [0, 1], applies contrast and a power curve, then smooths with Gaussian blur.

**Output encoding:** Single-channel grayscale. White = high specularity, black = low specularity.

**Expected output:** Bright areas on surfaces with high luminance and low saturation (polished metal, glass). Darker areas on saturated colors and dark surfaces.

### Parameters

| Parameter | Type | Default | Valid Range | Description |
|-----------|------|---------|-------------|-------------|
| `sat_weight` | float | 0.5 | [0.0, 1.0] | Saturation reduction factor. At 0.0, specularity depends only on luminance. At 1.0, saturated areas lose specularity aggressively |
| `contrast` | float | 1.3 | [0.5, 3.0] | Output contrast multiplier |
| `power` | float | 1.2 | [0.5, 3.0] | Specular falloff exponent. Above 1.0 darkens non-specular areas |
| `blur` | float | 0.5 | [0.0, 5.0] | Output smoothing sigma |

**Comparison tolerance:** 2
## Material fields

The original six map generators remain available. Advanced bundle generation
adds [detail, physical normals, signed curvature, wear and layer weights](material-fields.md)
with explicit scalar inputs and physical units. Use the
[bundle workflow](material-bundles.md) to resolve these dependencies together.
